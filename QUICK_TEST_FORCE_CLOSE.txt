   OPSI 1: Enable Testing Mode (Recommended)
   ----------------------------------------
   Buka console (F12), paste ini:

   location.reload();
   
   → Booking akan OPEN kapan saja

   OPSI 2: Tunggu Sampai Thursday
   -------------------------------
   Booking akan otomatis open di:
   - Thursday (hari 4)

   - Saturday (hari 6)
   Sebelum jam 22:00

   OPSI 3: Ubah Logic Production Mode
   -----------------------------------
   Edit BookingSystemDB.jsx line ~405:
   
   // Dari:
   const isBookingDay = (dayOfWeek >= 4 && dayOfWeek <= 6);
   
   // Jadi:
   const isBookingDay = true; // Allow every day

📋 PENJELASAN LOGIC:

   Priority:
   1. Force Close = true → CLOSED (tertinggi)
   2. Testing Mode = true → OPEN (bypass hari)
   3. Production Mode → Cek hari (Thu-Sat only)

   Sekarang:
   - Force Close: false ✅
   - Testing Mode: false (production) ✅
   - Hari: Sunday ❌ (bukan Thu-Sat)
   → Result: CLOSED ✅ (sesuai design)
