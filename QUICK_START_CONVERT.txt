📋 CARA PALING MUDAH (WINDOWS):

2. Tunggu proses selesai

4. Buka dan print!

═══════════════════════════════════════════════════════════════

📋 CARA MANUAL (SEMUA OS):

1. Buka Command Prompt / Terminal
2. Masuk ke folder booking-system:
   
   cd booking-system

3. Install library (hanya sekali):
   
   pip install python-docx

4. Jalankan script:
   
   python convert_md_to_word.py

5. File Word akan dibuat: TESTING_MANUAL_LENGKAP_COMBINED.docx

═══════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING:

Error: "python: command not found"
→ Install Python dari https://www.python.org/

Error: "No module named 'docx'"
→ Jalankan: pip install python-docx

Error: "File not found"
→ Pastikan Anda di folder booking-system

File Word corrupt
→ Hapus file .docx dan convert lagi
