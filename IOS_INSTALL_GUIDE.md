# 📱 Cara Install EYSA App di iOS (iPhone/iPad)

## Langkah-langkah Install

### 1. Buka Safari
- **PENTING**: Harus menggunakan **Safari browser**, bukan Chrome atau browser lain
- Buka: https://www.eysalanguange.center

### 2. Tap Share Button
- Tap tombol **Share** (ikon kotak dengan panah ke atas ⬆️)
- Tombol ini ada di **bagian bawah** layar (iPhone) atau **bagian atas** (iPad)

### 3. Add to Home Screen
- Scroll ke bawah di menu Share
- Cari dan tap **"Add to Home Screen"** (Tambahkan ke Layar Utama)
- Ikon: kotak dengan tanda plus (+)

### 4. Konfirmasi
- Edit nama app jika perlu (default: "EYSA")
- Tap **"Add"** di pojok kanan atas

### 5. Selesai! 🎉
- Icon EYSA akan muncul di home screen
- Tap icon untuk membuka app
- App akan buka dalam mode fullscreen (seperti native app)

## Troubleshooting

### Tidak ada opsi "Add to Home Screen"?
- ✅ Pastikan menggunakan **Safari** (bukan Chrome/Firefox)
- ✅ Pastikan iOS versi 11.3 atau lebih baru
- ✅ Coba refresh halaman dulu (tarik ke bawah)

### Icon tidak muncul?
- Cek di halaman home screen lain (swipe ke kiri/kanan)
- Atau cek di App Library (swipe ke paling kanan)

### App tidak buka fullscreen?
- Pastikan tap icon dari home screen, bukan dari Safari bookmark
- Jika masih tidak fullscreen, coba uninstall dan install ulang

## Fitur iOS PWA

✅ **Fullscreen** - Tidak ada address bar Safari  
✅ **Offline** - Bisa dibuka tanpa internet (cache)  
✅ **Fast** - Loading lebih cepat dari web biasa  
✅ **Native Feel** - Seperti app dari App Store  
✅ **Push Notifications** - Terima notifikasi (iOS 16.4+)  

## Catatan

- iOS Safari **tidak support** install button otomatis seperti Android
- Harus install **manual** lewat Share menu
- Ini adalah keterbatasan iOS, bukan bug aplikasi
- Semua PWA di iOS harus install dengan cara yang sama
