📋 STEP 1: SETUP API FUNCTION DI SUPABASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ ] 1. Buka Supabase Dashboard > SQL Editor
[ ] 2. Copy SQL dari: database/CREATE_API_INCREMENT_WEEK.sql
[ ] 3. GANTI 'eysa-auto-week-2026-xyz123' dengan API key rahasia Anda
    Contoh: 'eysa-secret-key-abc123def456'
[ ] 4. Run SQL
[ ] 5. Test: SELECT api_increment_week('your-api-key-here');
[ ] 6. Verify: Harus return {"success": true, ...}
[ ] 7. SIMPAN API key ini untuk Step 2

📋 STEP 2: SETUP GITHUB SECRETS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ ] 1. Go to: GitHub repo > Settings > Secrets and variables > Actions
[ ] 2. Click: New repository secret

[ ] 3. Add Secret #1:
    Name:  SUPABASE_URL
    Value: https://your-project.supabase.co
    (dari: Supabase > Settings > API > Project URL)

[ ] 4. Add Secret #2:
    Name:  SUPABASE_ANON_KEY
    Value: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
    (dari: Supabase > Settings > API > anon public key)

[ ] 5. Add Secret #3:
    Name:  SUPABASE_API_KEY
    Value: eysa-secret-key-abc123def456
    (API key yang Anda buat di Step 1)

[ ] 6. Verify: Semua 3 secrets sudah tersimpan

📋 STEP 3: PUSH KE GITHUB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ ] 1. File workflow sudah ada: .github/workflows/auto-increment-week.yml
[ ] 2. Commit & push:
    git add .
    git commit -m "Setup auto-increment week"
    git push
[ ] 3. Go to: GitHub repo > Actions tab
[ ] 4. Verify: Workflow "Auto Increment Week" muncul
