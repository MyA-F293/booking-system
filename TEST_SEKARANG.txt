TUJUAN: Tentukan apakah masalahnya RACE CONDITION atau TRIGGER BLOCK

═══════════════════════════════════════════════════════════
📋 STEP 1: Run SQL - Check Database
═══════════════════════════════════════════════════════════

1. Buka Supabase SQL Editor
2. Run query: database/DEBUG_WHAT_TRIGGER_SEES.sql
3. Lihat output:

   JIKA ADA SCHEDULE (tanpa program filter):
   → 🚨 TRIGGER BLOCK! (bukan race condition)
   → Ada schedule dari program lain
   → Trigger block karena tidak cek program
   → SOLUSI: Drop trigger

   JIKA TIDAK ADA SCHEDULE:
   → ✅ Database bersih
   → Lanjut ke Step 2

═══════════════════════════════════════════════════════════
📋 STEP 2: Test Browser - Single User
═══════════════════════════════════════════════════════════

1. Hard refresh browser (Ctrl + Shift + R)
2. Open Console (F12)
3. Login sebagai 1 student
4. Click book Oxford Saturday Evening
5. LIHAT CONSOLE LOG:

   JIKA ERROR:
   → 🚨 BUKAN race condition! (cuma 1 user)
   → Trigger atau constraint block
   → Lihat error message di console
   → SOLUSI: Drop trigger/constraint

   JIKA SUCCESS:
   → ✅ Single user works
   → Mungkin race condition (perlu test multiple users)
   → Lanjut ke Step 3

═══════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════
📊 ANALISIS CONSOLE LOG
═══════════════════════════════════════════════════════════

Cari pattern ini di console:

PATTERN 1: Trigger Block
```
❌❌❌ INSERT FAILED!
🔴 ERROR DETAILS:
   - Message: Duplicate schedule detected!
   - Code: P0001
📊 SELECT RESULT:
   - Found: false
   - ⚠️ NO SCHEDULE FOUND!
```
→ INSERT failed tapi SELECT tidak find schedule
→ Trigger block INSERT tapi schedule tidak ada (dengan program filter)
→ SOLUSI: Drop trigger

PATTERN 2: Race Condition (Handled)
```
❌❌❌ INSERT FAILED!
🔴 ERROR DETAILS:
   - Message: duplicate key value violates unique constraint
   - Code: 23505
📊 SELECT RESULT:
   - Found: true
   - Schedule ID: [uuid]
✅✅✅ SUCCESS: Found existing schedule!
```
→ INSERT failed, SELECT find schedule
→ Code handle dengan baik
→ SOLUSI: Tidak perlu fix, code sudah benar

PATTERN 3: Race Condition (Retry)
```
❌❌❌ INSERT FAILED!
📊 SELECT RESULT:
   - Found: false
⏳ RETRY MECHANISM:
   - Waiting 50ms before retry 1/5...
[after retry]
✅✅✅ SUCCESS: Found existing schedule!
```
→ INSERT failed, SELECT tidak find (timing issue)
→ Retry dan find schedule
→ SOLUSI: Tidak perlu fix, code sudah handle

🎯 KESIMPULAN
═══════════════════════════════════════════════════════════

Setelah test, kita akan tahu:

1. **Trigger Block** → Drop trigger dengan `DROP_TRIGGER_NOW.sql`
2. **Race Condition** → Code sudah handle, tidak perlu fix
3. **Constraint Issue** → Drop constraint yang salah
4. **RLS Policy** → Fix RLS policy
