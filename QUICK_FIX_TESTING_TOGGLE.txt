❌ MASALAH:
   Tekan tombol "Testing" tapi database tidak berubah

🔍 ROOT CAUSE:
   toggleBookingMode() adalah async function
   Tapi onClick tidak pakai await
   → Function return sebelum database update selesai

✅ SOLUSI:
   Tambah async/await di button onClick

🔧 YANG SUDAH DIPERBAIKI:

   File: AdminBookingDashboard.jsx (line ~1088)
   
   SEBELUM:
   onClick={() => {
       toggleBookingMode();  // ❌ No await
       toast.success(...);
   }}
   
   SESUDAH:
   onClick={async () => {
       try {
           await toggleBookingMode();  // ✅ Wait for DB
           toast.success(...);
       } catch (error) {
           toast.error('Failed to change booking mode');
       }
   }}
